## 一、游戏简介

《赶赶嗨嗨！》是一款以赶海为主题的记忆配对消除小游戏，翻开沙格，记住藏在下面的扇贝、螃蟹、小虾等物品，找到相同的一对，将他们配对消除。在涨潮前完成全部配对即可过关，其中，潮水会随时间逐渐上涨，配对成功会奖励一定时间。

游戏包含五个大关、共50关，从阳光浅滩到月下海岸、海草礁间和风浪海湾。每个大关都有贯穿其中的独特机制：迷雾会遮住视线，海草会在失误后传播，海浪会暂时封住部分格子……配对顺序、限时连续配对等多样的条件，也会让熟悉的玩法产生新的挑战。旅途中还在每个大关穿插了特殊玩法的小游戏（第5、6关）。其中，第五个大关专门设计了各种挑战与创意关卡，营造特殊的消除体验。

本游戏的核心创意是将“涨潮前赶海”的紧迫感融入记忆配对，用逐步变化的规则，让玩家不断调整观察、记忆与操作策略。在轻松可爱的海边氛围中，消磨自己的时间。

## 二、创作出发点

《赶赶嗨嗨！》希望把“在涨潮前寻找海边收获”的体验，结合记忆配对，变成一个操作简单、以消除为主的休闲小游戏。玩家通过点击扫开沙格，看到藏在下面的扇贝、螃蟹、小虾等物品，依靠记忆把相同的收获配成一对，装进桶里。普通的配对消除游戏，也会有时间的要求，但是这样玩家会陷入“点击 - 消除 - 看时间”的循环，为此本游戏添加了全隐藏：需要玩家自己逐步翻开格子探索可配对物品的核心玩法，在基础的消除体验上增加一个维度。

游戏选择赶海为主题，是因为它能把几个玩法要素自然联系起来：沙格隐藏对应的物品信息，翻开沙子对应探索，装物品的桶代表进度，潮水对应不断流逝的时间，而且海边的主题背景也方便后续加入新的机制，更新关卡的操作体验。

游戏面向喜欢轻量益智、记忆挑战和短关卡体验的玩家。设计目标是在容易理解的基础上，让玩家持续遇到新的判断博弈：先翻哪里、什么物品要留到最后、失误后怎样调整，以及何时追求速度、何时谨慎确认。同时后续各种新增机制也让玩家需要根据具体情况作出更多的实时决策，增强玩家的成就感。

关于游戏命名的由来，《赶赶嗨嗨！》这个名字一眼就能看出赶海的主题，且把“海”换成“嗨”符合可爱、热情的主题，而且叠词的运用也体现了游戏配对消除的主题。

为了提高可玩性和关卡丰富度，游戏设计了带有不同独特机制的大关，每个大关设计了特殊玩法的小游戏，并且还有许多丰富的通关条件和其他设计参与其中。

## 三、基础玩法与设计

普通关卡的流程如下：

1.点击尚未翻开的沙格，查看并记住其中的物品。

2.再翻开另一格；两件物品相同，则成功配对并收入桶中。

3.两件物品不同，则在短暂展示后盖回，玩家可以利用这次翻开沙格留下的记忆继续寻找，回到步骤1。

4.在潮水涨满前完成全部配对。有关卡附加条件时，还需同时满足这些条件。

### 1.可配对物品的设计

在整个游戏流程中，最多会出现6种物品（扇贝、螃蟹、小虾、海螺、鱼儿、八爪鱼）。第一关只有3种物品，物品的种类会随着游戏进度增加，最后增加到6种。对于这种记忆消除游戏，物品的种类不能太少，这样会让游戏缺乏新鲜感，且难度过低，物品种类过多，又会使玩家难以记住某些物品的形状，很难实现让玩家“看一眼就判断出这个东西是什么并记住”的效果。最终定为6种物品。![六种物品介绍](/Users/nekomimi/tidepooling/图片/六种物品介绍.png)

在这种消除游戏中，待消除的物品的美术设计是很重要的，物品既要设计得清新可爱，让玩家看的舒服，也要设计得有明显的区别，这里的区别需要是多层次的，物品不同，不能只是形状不同，最好让它的颜色也不同，这样才能让玩家一眼区分开不同的物品，最快速地形成记忆。同时，颜色的设计也要尽量避免色差过大，比如深红和深蓝两个极端色调最好不要频繁出现在一起，整个物品系统的配色应该尽量温和，过渡平缓。

### 2.普通关卡的参数设计

参数涵盖局内时间，关卡条件、物品种类，格子数量等。

普通的关卡大多以60s为初始时间，在配对成功后会获得5秒的奖励时间，且这个时间不会溢出（连续配对让计时起点变为负数）。这样的时间系统设计让大部分关卡都变的较为简单，符合轻松休闲游戏的初衷。

那么想让关卡难一点怎么办？有以下几种办法：增加物品种类，增加格子数量，增加新的机制，增加通关条件。前面的三者在游戏中的某个阶段基本处于固定的状态，或者说难以有合适的改变，因此用的最多的关卡变量其实就是通关的条件，实际上在当前的50关中，相当一部分关卡都有通关的条件，这些条件有的增加难度，有的只是增加了博弈性。在游玩中，通关条件设计的初衷是想在现有机制下增加玩家的决策复杂度和体验感，同时让玩家能体会到“我克服了以上艰难险阻后通关”的成就感。实测也是如此，一个很普通的条件，配合一些关卡独特的机制，可能就让决策难度加倍。

对于条件的设计，不应该在每次想添加条件时就随机想一个，而是应该定下几个类别，通过参数的改变来便于后期方便地复用这些条件，降低实现复杂度。比如在游戏中实装的计时类条件有：配对失败会扣时间，配对成功将没有奖励时间，在m秒内完成n次配对等。

![截屏2026-11-06 14.53.58](/Users/nekomimi/Library/Application Support/typora-user-images/截屏2026-11-06 14.53.58.png)

对于倒计时的设计，我认为单纯的数字倒计时非常的死板，玩家每次想看剩余时间的时候都需要去瞟一眼固定的位置，而且很不直观。因而设计了逐渐覆盖全屏的半透明潮水，不会遮挡视线。画面中的半透明潮水随时间上涨，成功加时则表现为退潮，这样的设计充分融入了赶海的风格，符合涨潮的设计，且让玩家对剩余时间一目了然。水下的普通沙格仍可以操作；潮水本身负责传达时间压力，而且在时间所剩无几时（设计为10秒以内），屏幕的周围会有红光闪烁，营造危急感。收入桶中的物品会让收获桶逐渐装满，为配对结果提供持续可见的反馈。

![截屏2026-11-06 15.11.15](/Users/nekomimi/Library/Application Support/typora-user-images/截屏2026-11-06 15.11.15.png)

对于物品种类，游戏并没有单纯地过一关就加一个，而是营造不同的时机来加入新的物品，让难度曲线更加平滑，不会让玩家短时间出现记忆疲劳。

对于物品的种类个数和排列顺序，大部分关卡采用了固定的排列（即重新进入后物品的位置是不变的），一是因为固定和随机在关卡体验上并没有太大的区别，这样可以降低复杂度；二是因为固定的排列让很多较难的关卡有了暴力解：一个个记住总能配对完成，因此不会出现完全过不了的关（但是其实通关全部关卡并不需要这样做，所有关卡实测都能在适当的记忆负荷下通过）。

### 3.每个大关加入独特的机制

由于已经有了一个背景主题，而赶海的主题可以很自然地延伸到别的场景，就很自然地想到把50个小关拆分成5个大关，每个大关10个小关。实际上的开发过程也是如此：比如第二大关的设计其实在还没有想到“应该设计一个第二大关与第一大关做区分”之前就有了，是先是想到晚上也能赶海，才有“晚上可以单独设计为一个主题大关”的主意。

那么有了不同的大关，不加入点新东西不是太说不过去了吗？这样的设计在很多休闲游戏中都能找到，比如《植物大战僵尸》和《保卫萝卜》。于是我开始思索对每个大关应该添加什么贯穿整个大关流程的特殊机制，最后思索出来了，就实装了。实际上这部分的思考过程并没有花很多时间，大部分都是突然想到，然后经过几次废弃或修改就得到满意结果了，大部分时间花在试玩和修改上。

| 机制             | 当前规则                                                     | 希望产生的判断                                               |
| ---------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 迷雾（第二大关） | 覆盖指定区域，需要先点击拨开才能对制定沙格操作；拨开后5秒恢复，也遮住已收集空位的状态 | 利用短暂可见窗口记住信息，决定先查看哪一片区域，记住雾下的格子是否已经被配对。制定自己的消除策略：是先消除某个区域后推进，还是随机边点边记？ |
| 海草（第三大关） | 海草格可以直接翻开，海草配对失败会向上下左右相邻格传播，原海草格锁定10秒并变为紫色 | 让失误影响后续可用空间，促使玩家谨慎处理风险区域，让玩家选择冒风险进行新的配对还是苦等时间后再稳定消除，海草锁定时还会让玩家逐渐损失记忆 |
| 海浪（第四大关） | 提前预警，随后遮住随机行或列，使其暂时不可操作，并按关卡配置扣除时间 | 预先观察目标区域，在冲刷期间调整操作顺序，等待区域重新开放，同时，海浪这种视觉冲击力较大的事件也会干扰玩家的记忆 |

可以看到，第五大关是没有什么新的机制的，实际上这也是我设计的一部分：我本想把第五大关也设计为一个有新主题的大关，但是之后我脑子里突然就有很多非常规的关卡设计，而且这些设计都是利用了以前已经有的元素，后来我敲定了：我应该设计一个专门存放自己的小巧思的大关，这样在保证可玩性的同时，相比普通的大关更能给玩家留下印象（有种让别人猜不到自己想干什么的感觉），顺便满足一下自己。

### 4.用小游戏调节长流程中的节奏

每个大关的第五、六关都设计了不同的小游戏（在选关界面中用红色标出），玩家可以从记忆配对暂时切换到各式各样的其他小游戏中，保证主题不跑偏的同时带给玩家崭新的体验。

- 第一大关的小游戏：数独填图

![截屏2026-11-06 18.32.36](/Users/nekomimi/Library/Application Support/typora-user-images/截屏2026-11-06 18.32.36.png)

在这个小游戏中，玩家需要在给定时间内填满整张图，并满足横、纵、对角线没有相同物品的条件。

这个小游戏的设计灵感就是来自数独，我想，数独就是由1到9组成的带条件填空游戏，那么我刚好设计了这么多种物品，拿它们做数独不是刚好？于是就有了第一大关的小游戏：数独填图。

- 第二大关的小游戏：雾中寻物

这个小游戏利用了第二大关有雾的特性，玩家需要在给定时间内记住物品的初始摆放位置，然后在一定时间内根据随机生成的寻物需求去寻找对应的物品，而且在移动时能见度很低。如果没找到，则会导致潮水大幅上涨，提升紧迫感的同时不至于给予一击致命的惩罚。

这个大关的小游戏只是想利用一下自己设计出来的雾，而一提到遮蔽视野，自然就想到迷宫寻物这种玩法，随机刷新的寻物需求要求玩家必须真正记住各个物品的方位，而不是靠蒙（虽然有时候还是能蒙过）。

![截屏2026-11-06 18.45.50](/Users/nekomimi/Pictures/截屏2026-11-06 18.45.50.png)

- 第三大关的小游戏：海草翻转

在这个小游戏中，玩家开始会面对一个某些格子被海草覆盖的棋盘，玩家点击任意一个格子，这个格子本身和上下左右相邻的格子都会反转：有海草的变成没有海草，没有海草的则长出海草。在一定时间内消除所有海草即可。它的灵感来源是一类经典的算法题：关灯问题，比如力扣第1284题。虽然算法题很难（我本人也写不出来），但是放在游戏里就可以寻找到技巧了。

这个小游戏只是把海草当作一个载体，可以说是象征性地利用了第三大关的特色，实际上这个玩法跟海草没有什么关系……还是有一点关系，因为海草会在相邻的地方蔓延。实测，这关如果没有找到技巧，就会是很折磨的。

![截屏2026-11-06 18.54.36](/Users/nekomimi/Library/Application Support/typora-user-images/截屏2026-11-06 18.54.36.png)

- 第四大关的小游戏：分类装桶

在这个小游戏中，玩家会面对被打乱顺序分布在若干桶中的各种物品，并拥有两个空桶（4-6只有一个），玩家每次只能取出一个桶中最上层的物品，然后把它放到和他一样的物品上面，玩家需要在给定时间内按上述的过程将所有的物品分好类，装到单独的桶中。

这个小游戏的灵感是《蜘蛛纸牌》，只不过把接龙变成了配对，而且减少了种类。其实我最开始觉得这个游戏还蛮难的，后面不知为什么突然开窍了就越来越得心应手了，但是游戏中实装的还是简化难度过的版本。同时，为了防止其过于简单，撤回的次数从最初的无限次变成了1次。![截屏2026-11-06 19.05.52](/Users/nekomimi/Library/Application Support/typora-user-images/截屏2026-11-06 19.05.52.png)

## 5.其他

## 四、五个大关的定位

| 大关     | 主要内容                                 | 定位                                                         |
| -------- | ---------------------------------------- | ------------------------------------------------------------ |
| 初入浅滩 | 暂不添加特殊机制；引入小游戏和条件机制   | 让玩家训练基础的操作，养成心得，并理解游戏的条件和小游戏机制，以及物品种类的添加 |
| 月下独捉 | 夜间海滩与迷雾；雾中寻物小游戏           | 引入大关的特殊机制，让玩家对每个大关有一定期待；拓展玩家的游玩体验 |
| 礁间寻宝 | 礁石滩与海草传播；海草翻转小游戏         | 通过新的机制延续玩家的期待和体验；让玩家重新回到日间，带来视觉上的新体验，营造旅途感 |
| 踏浪而寻 | 风浪海湾与周期性海浪冲刷；分类装桶小游戏 | 构建完整的赶海世界观，至此玩家已经去到了多个场景去赶海，同时新的机制和小游戏继续让玩家保持新鲜感，为最后一个大关的收束做铺垫 |
| 挑战EX   | 重组既有机制并加入特殊挑战               | 让玩家猜测下一个大关的主题的想法直接被根本否决：这一大关没有新的主题机制，并结合创意玩法营造反差感，让旅途不按常规结局结束。5-10的设计用于表达感谢：作者的心，配对玩家的心。 |

对于各个小关，每个小关都通过棋盘大小，物品种类，时间，特殊机制作用区域分布和额外通关条件，小游戏等共同调节，降低游玩时感到单调的可能性。

## 五、视觉与交互设计

游戏本体采用浅黄色沙滩主题界面和清晰圆润的物品图案，采用沙黄+浅蓝+清新绿的主题配色。沙格、按钮和弹窗等都使用圆角矩形轮廓，结合阴影和些许的渐变色，表现元素的质感。沙格被匹配后时也保留独立边界，使密集棋盘仍能辨认格子位置。

各个大关的场景在选关界面结合大关的主题设计不同的背景，切换时在相邻章节加入双向衔接过渡动画。同时，游戏主页和设置页面也有独特的背景（虽然后来设置被移除了）。特殊关卡或小游戏关卡在选关界面用与普通关卡不同的红色标注出。另外，已经通关的关卡也会在选关界面标注。

首次教学让玩家亲自经历配对成功、失败与潮水说明。新机制和附加条件在需要时通过入场提示介绍，规则阅读期间不计时。局内及暂停界面保留必要的条件状态。游戏以竖屏为主要布局，同时针对不同窗口尺寸调整棋盘和面板。暂停或切到后台会暂停相关计时。长窗口可滚动。正常通关记录保存在当前文件中，因此在线试玩不会保存进度。

当配对成功时，配对成功的物品会展示“跳出，进入桶中，桶摇晃”的动画，并加入独立音效，让配对成功的反馈更加直观生动，且装有收获物品的桶会不断装满，增加玩家的成就反馈。在成就达成时也会有短暂的顶部弹窗和专属音效。
